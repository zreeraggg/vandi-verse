# Pickup textures

Cropped from reference sheets of the coins and the motta puffs. Each face has a greyscale `_bump` partner that `src/world.js` uses for relief.

| File | Used for |
|---|---|
| `coin1_tails` / `coin1_heads` / `coin1_edge` | ₹1: numeral side toward the runner, Lion Capital on the back, reeded rim |
| `coin5_tails` / `coin5_heads` / `coin5_edge` | ₹5, same layout |
| `puff_top`, `puff_layers` | puff dome (top-down view) and the pastry layers round the base |

There's no ₹2 coin in the game any more.
